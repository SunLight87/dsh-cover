# 字体系统 + 压字坐标表

## 一、字体系统（AI 出图阶段只需声明，实际渲染靠字体）

全图**只有 3 个字重层级**，清一色无衬线。无书法体、无宋体、无描边字、无立体字、无渐变字。

| 层级 | 用途 | 特征 | 可对应字体 |
|------|------|------|-----------|
| **L1 超粗黑** | 主标题、面板大数字 | 笔画等宽、笔端平切、字面撑满字框、字距收紧 -2%~-4% | 思源黑体 Heavy / 阿里巴巴普惠体 Heavy |
| **L2 几何特粗数字** | `3000` `227` `30%` `5.9%` `4200` | 几何骨架、字腔大、比中文标题再大 1.2–1.6 倍 | Archivo Black / Poppins ExtraBold |
| **L3 中黑 / 常规黑** | 面板标题、导语、正文、页脚 | 字号约为标题的 1/6 – 1/10，行距 1.35–1.5 | 思源黑体 Bold / Medium / Regular |

**细节规范**
- 标题**左对齐、顶格**，绝不用居中（居中会立刻失去报纸感）。
- 面板标题白字压在色条上，`01` 与标签之间用一条**细竖线**分隔。
- 标点用全角，句末句号 / 感叹号加重语气（`越打越狠！`、`22年新高！`）。
- 文字**不加投影**（深色底变体除外，会有一层极淡的暗色 lift）。

## 三、对齐与安全规则

1. 所有文字**左对齐顶格**，唯一例外是右上角期号与日期行（右对齐）。
2. 标题最长一行**不得越过 x = 700**（右侧 35% 是配图区），越界就手动断行或缩 2px 字号。
3. 文字与底图元素之间留 **≥ 12px** 呼吸位，不要贴着色条或图标。
4. 面板正文每栏**不超过 3 行**，超出就删字，不要缩字号。
5. 全图**只用 3 个字重层级**，不要引入第四种。

## 四、三个工具的落地方式

- **Figma**：底图作为 frame 背景 → 新建 text layer 按上表定位 → 用 Auto Layout 做三栏等分（gap 16px）→ 导出 PNG 2x。
- **PPT**：幻灯片尺寸设为 10.86 × 14.48 cm（或等比放大）→ 底图铺满 → 文本框取消自动缩放、手动定位 → 另存为 PNG。
- **HyperFrames**：底图作为 `background-image` 的 track 元素，文字用绝对定位 + `data-start` 做逐行入场；
  字体通过 `@font-face` 引入思源黑体 Heavy 与 Archivo Black 的本地 woff2。

## 五、压字后自检 5 条

1. 缩小到 20% 看，标题是否仍然一眼可读？（封面在小红书信息流里就是这个尺寸）
2. 有没有任何文字压到配图块或图标上？
3. 红色是否**只**出现在数字、关键动词、警示条、01/03 面板头？（红色滥用会立刻掉档）
4. 全图数一下字重层级，是否 ≤ 3 种？
5. 四边留白是否均匀 ≥ 20px？
