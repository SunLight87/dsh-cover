# 配色系统（CSS 变量）

> 像素级采样自 19 张真实封面。**直接复制下面这块 `:root`，不要改色值。**

```css
:root{
  --red:#C41E1B;      /* 正红   —— 关键数字 / 关键动词 / 警示条 / 01·03 面板头 */
  --navy:#0B2A5B;     /* 深藏蓝 —— 刊头 / 通栏分隔线 / 02 面板头 */
  --blue:#12368F;     /* 宝蓝   —— 标题里被强调的「词」（非数字） */
  --ink:#111111;      /* 墨黑   —— 标题主色 / 正文 */
  --grey:#999999;     /* 灰     —— 页脚 */
  --pink:#FDEDED;     /* 浅红底 —— 01 面板 */
  --sky:#EAF1FA;      /* 浅蓝底 —— 03 面板 */
  --paper:#FFFFFF;    /* 纯白底 */
}
```

## 色板与用途

| 角色 | 色值 | 实测区间 | 用途 |
|------|------|----------|------|
| 正红 | `#C41E1B` | #B5271D – #C72B1F（Hue ≈ 4°） | 关键数字、关键动词、警示条、01/03 面板头 |
| 深藏蓝 | `#0B2A5B` | #0D295B | 刊头、通栏分隔线、02 面板头、期号 |
| 宝蓝 | `#12368F` | #123171 / #133599 | 标题中被强调的**词** |
| 墨黑 | `#111111` | — | 标题主色、正文 |
| 浅红底 | `#FDEDED` | #FCF3F4 | 01 / 03 面板背景 |
| 浅蓝底 | `#EAF1FA` | #EEF3FA | 02 面板背景 |
| 灰 | `#999999` | — | 页脚免责声明 |

**配色比例 ≈ 白 60% / 黑 18% / 红 15% / 蓝 7%**

## 语义规则（整套风格辨识度的来源）

- **红** = 下跌、风险、冲击、关键数字
- **蓝** = 结构、中性、上升、被强调的名词
- **黑** = 事实陈述、主体名词

同一句话里红蓝黑交替出现，形成节奏。

> ⚠️ **红色滥用会立刻掉档。** 红色只允许出现在：数字、关键动词、警示条、01/03 面板头。
> 其余一律黑或蓝。

## 变体 C（深色冲击）

```css
.cover{background:#06080E;}
.hl{color:#FFFFFF;}
.hl .red{color:var(--red);}
.alert{border-color:var(--red); background:#FFFFFF;}  /* 警示条保持红框白底 */
```

## 禁用

- 不要出现紫、青、粉、马卡龙色
- 不要用渐变填充文字（`background-clip:text` 一律禁止）
- 不要引入第四种强调色
- 金色 `#E0A83C` 只允许出现在金融图标内部，面积极小
