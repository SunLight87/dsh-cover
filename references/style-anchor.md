## 三个不可动摇的结构约束

1. **刊头栏只放项目 logo + 项目名称**，字号要大（`60px/900`），不放期号以外的杂物。
2. **标题字数少的行必须加宽**，用 flex `space-between` 让各行总宽一致。
3. **底部警示条 = 红色正方形底 + 白色圆圈 + 加粗惊叹号**，三者缺一不可。

## 三种变体

| 变体 | 触发条件 | 关键差异 |
|------|----------|----------|
| **A 完整信息图** | 内容含 ≥ 3 组数据 | 九段横带全开（默认） |
| **B 极简大字** | 单一爆点、标题即全部 | 删掉三栏与主视觉，标题提到 `120px`，底部只留细线 + 3 个参数 |
| **C 深色冲击** | 危机、暴跌、黑天鹅 | 底色换 `#06080E`，标题白 + 红，警示条保持红框白底 |

## 与 AI 生图方案的对比（为什么改）

| | AI 生图 | 代码生成（本方案） |
|---|---|---|
| 中文正确率 | ~0%（必糊） | **100%** |
| 版式精度 | 靠运气 | 像素级可控 |
| 改一个字 | 重新抽卡 | 改一行 HTML |
| 可复用 | 每次重新描述 | 模板 + 变量 |

**任何时候都不要调用 AI 生图模型。**
