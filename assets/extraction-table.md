# 第 0 步 · 意象提取表模板

> 每次收到文案或标题，**先填这张表**，再出提示词。表填不出来，说明文案还没读懂。

| 槽位 | 说明 | 示例 |
|------|------|------|
| `{{SUBJECT}}` | 核心主体：一个可被画出来的具体物件，不要抽象名词 | 印着 AI 的芯片 / 断裂的供应链 / 下沉的天平 |
| `{{NUMBER}}` | 数字锚点：文案里最狠的那个数，作为画面最大视觉元素 | `3000亿` / `-5.9%` / `4200亿` |
| `{{POLARITY}}` | 情绪极性：下跌/风险 → 红为主；增长/利好 → 红蓝对撞；中性 → 蓝为主 | 下跌 |
| `{{INDUSTRY}}` | 行业符号 2–4 个（进入图标栏） | 芯片、服务器、光模块、液冷 |
| `{{METAPHOR}}` | 隐喻动作：把新闻翻译成一个动作 | 踩刹车 / 决堤 / 抢位 / 挤泡沫 |
| `{{SECTIONS}}` | 三栏小标题，按 `数据 → 变化 → 影响` 生成 | 核心数据 / 市场变化 / 直接影响 |
| `{{TAKEAWAY}}` | 底部红条结论，≤ 28 字，含 1–2 个红字关键词 | AI 竞赛还在加码，但债市已开始追问回报。 |

## 三条提取铁律

1. **数字 > 形容词** —— 文案里只要有数字，就让数字当视觉主角。
2. **动词 > 名词** —— `暴跌` 比 `下跌趋势` 好画 10 倍。
3. **一个画面只讲一件事** —— 超过 3 个意象就砍到 3 个。

## 三栏小标题的常见变体（任选一组，保持三段式节奏）

| 组 | 01 | 02 | 03 |
|----|----|----|----|
| A（默认） | 核心数据 | 关键变化 | 直接影响 |
| B | 核心消息 | 为什么踩刹车 | 直接影响 |
| C | 发生了什么 | 为什么重要 | 普通人要看 |
| D | 核心数据 | 结构变化 | 市场提醒 |
| E | 核心数据 | 最大变化 | 产业链受益 |
| F | 关键窗口 | 真实能力 | 市场影响 |

## 底部结论的写法

- 用「A 结束了，B 刚开始」这类**转折句式**，比陈述句更有传播力。
- 必须含 1–2 个会被标红的词（数字、关键动词、行业名词）。
- 不超过 28 字，两行以内。
