# dsh-cover

**中文财经 / AI 资讯「信息图封面」提示词生成器 + 排版规范** —— 给 AI Agent 用的 Skill。

给它一段**文案**或**标题**，它产出：

1. **意象提取表** —— 主体 / 数字 / 情绪极性 / 行业符号 / 隐喻 / 三栏小标题 / 底部结论
2. **无文字底图提示词**（中 / 英双语，可直接粘贴）
3. **压字坐标表** —— 逐区 y 坐标与字号（思源黑体 Heavy + Archivo Black）

```
文案/标题  →  ① 意象提取表  →  ② 无文字底图提示词  →  ③ 压字坐标表
```

## 为什么是「无文字底图 + 压字」两段式

AI 画版式骨架很强，写中文字几乎必糊（乱码、缺笔画、字形错误）。
把「排版骨架」交给 AI、「文字渲染」交给字体，成品率从 ~20% 提到 ~95%。

## 风格锚点

来自 19 张真实封面样本的像素级分析：

| 维度 | 规格 |
|------|------|
| 画幅 | 3:4 竖版，1086 × 1448 基准 |
| 底色 | 纯白 `#FFFFFF`，报纸头版 |
| 标题字 | 超粗黑体（思源黑体 Heavy），笔画等宽、笔端平切、字距 -2%~-4%、行高 0.95 |
| 数字字 | 几何特粗无衬线（Archivo Black 风格），比中文大 1.2–1.6 倍 |
| 三色 | 正红 `#C41E1B` ｜ 深藏蓝 `#0B2A5B` ｜ 宝蓝 `#12368F`，配墨黑 `#111111` |
| 面板底 | 浅红 `#FDEDED` / 浅蓝 `#EAF1FA` |
| 光影 | 主背景与文字图标 = 完全平光；仅配图块内部 = 写实光照 |
| 版式 | 九段横带瑞士网格，四边 20px 安全边距，内容宽度 96% |

## 安装

见 [INSTALL.md](INSTALL.md)。最快的方式：

```powershell
# DSH（本机技能目录）
Copy-Item -Recurse -Force . "$env:USERPROFILE\.dsh\skills\dsh-cover"
```

## 用法

安装后直接说：

> 做封面：OpenAI 发布 GPT-6，推理成本再降 80%

或显式调用 `/dsh-cover`。
